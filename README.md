# VEXEL Website

Website premium e seamless da VEXEL, construído com Vite, React, TypeScript, Tailwind CSS e Framer Motion.

## Visão

**Operational Intelligence. Executed.**

A VEXEL cria automação inteligente para empresas: chatbots, agendamentos, workflows, Voice AI e command dashboards.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form
- Zod
- Lucide React

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Backend Dart Frog

O formulário de diagnóstico já está preparado para comunicar com uma API Dart Frog através da variável:

```env
VITE_VEXEL_API_URL=https://api.vexel.systems
```

Enquanto a variável não existir, o envio funciona em modo mock no browser.
